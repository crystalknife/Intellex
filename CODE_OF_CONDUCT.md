# Code of Conduct

## Our Commitment

Intellex is committed to fostering a welcoming, respectful, and inclusive environment for everyone.

We believe that great software is built through thoughtful collaboration, constructive discussion, and mutual respect.

By participating in this project, you agree to contribute in a way that makes the community welcoming for all contributors regardless of experience level, background, identity, or perspective.

---

# Our Standards

Examples of behavior that contributes to a positive environment include:

- Being respectful and considerate.
- Providing constructive feedback.
- Assuming good intentions.
- Being open to different ideas and approaches.
- Accepting feedback gracefully.
- Helping others learn and grow.
- Focusing discussions on improving the project.

---

Examples of unacceptable behavior include:

- Harassment or discrimination of any kind.
- Personal attacks or insults.
- Trolling or inflammatory comments.
- Publishing private information without permission.
- Intentionally disrupting discussions or development.
- Any behavior that creates an unwelcoming environment.

---

# Project Philosophy

Intellex values thoughtful engineering over unnecessary complexity.

When discussing ideas:

- Debate the implementation, not the individual.
- Prefer evidence over assumptions.
- Keep discussions focused on solving problems.
- Respect differing technical opinions.

Healthy technical disagreement is encouraged when it improves the project.

---

# Scope

This Code of Conduct applies to:

- GitHub Issues
- Pull Requests
- Discussions
- Documentation
- Project communication channels
- Any other official Intellex community spaces

---

# Enforcement

Project maintainers are responsible for clarifying and enforcing this Code of Conduct.

Maintainers may remove, edit, or reject comments, commits, code, issues, or other contributions that violate these guidelines.

Repeated or severe violations may result in temporary or permanent restrictions from participating in the project.

---

# Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, please report it privately to the project maintainer through GitHub.

Reports will be reviewed respectfully and handled as fairly as possible.
